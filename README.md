# المشكاة

مشروع خيري مجاني لنفع المسلمين، بنية إهداء ثواب العمل إلى شهداء شبوة وجميع شهداء اليمن.

## هدف المشروع
- نشر الخير والذكر والدعاء.
- الدعاء لشهداء شبوة وجميع شهداء اليمن.
- الاعتماد على مصادر موثوقة عند إضافة القرآن الكريم والأحاديث.
- عدم نشر أسماء الشهداء أو بياناتهم الشخصية.

## حالة المشروع
نسخة تجريبية قيد التطوير. لم يتم اعتمادها كتطبيق نهائي بعد.
